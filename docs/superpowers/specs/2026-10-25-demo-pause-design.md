# 演播暂停 / 继续

日期：2026-10-25
状态：用户已同意，直接实现

## 做法

- 暂停只在步与步之间生效。worker 每一步开始前会运行 `ateam demo step`，暂停后服务不放行这条命令。
- 服务把这条命令挂起，最多 50 秒。期间用户点「继续」，就记下这一步并马上返回，worker 接着做。
- 50 秒后还在暂停，命令输出「# 演播已暂停」和一条带 `--round` 的同样命令，worker 原样再运行，继续等。等的时候不碰浏览器、不截图。
- 暂停期间点「叫停」照常生效，挂着的命令返回「已叫停」。
- 暂停期间派发保持冻结。worker 每次报到都会刷新租约，不会被判掉线。
- 看板显示：
  - 演播卡、演播横幅、提词小窗上，「停止」旁边有「暂停 / 继续」按钮。
  - 暂停中显示「已暂停」标签。
  - 时间线记下「暂停」「继续」。
- 运行记录 `run.pausedMs` 累计暂停时长。看板上的时长显示暂时没有扣除暂停时间。
